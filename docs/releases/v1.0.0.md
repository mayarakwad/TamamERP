**Tamam 1.0.0 is the first release.** It's one app for **businesses, schools and households** in Qatar, in full Arabic and English with a real right-to-left layout, Qatari riyal and Hijri dates.

## Install

**macOS / Linux**
```bash
curl -fsSL https://github.com/mayarakwad/TamamERP/releases/latest/download/install.sh | bash
```

**Windows (PowerShell)**
```powershell
irm https://github.com/mayarakwad/TamamERP/releases/latest/download/install.ps1 | iex
```

The installer checks for Node.js 22+, downloads this release, installs everything, prepares the database, builds and starts Tamam, and opens the setup wizard in your browser. Add `--demo` (Windows: `-Demo`) to start with three living demo workspaces instead.

**Server (Docker)**
```bash
git clone --branch v1.0.0 https://github.com/mayarakwad/TamamERP.git tamam && cd tamam
docker compose up -d && docker compose logs tamam
```

## What's in it

- **Setup:** a browser wizard for a new server, then a setup guide in each new workspace with steps for its type (branches and invoice bank details for a business; campuses, fees and online applications for a school; budgets and bills for a home).
- **Home:** expense claims with receipt photos and approvals, budgets, recurring bills with reminders, things you own with warranties, a monthly summary.
- **Business:** sales and purchases, inventory with low-stock alerts, HR, attendance, leave, payroll with the WPS salary file, and a double-entry ledger with profit & loss, balance sheet, cash flow and aging reports.
- **School:** admissions with an online application form, students and guardians, timetables, roll call, gradebook and bilingual report cards, fees with installments and sibling discounts, buses, the library, a parent view, and several campuses side by side.
- **Flow, the AI assistant:** answers from your own data (only what the person asking may see), explains the page, drafts messages and reports, fills in forms, and prepares changes you confirm with one click. It runs on each organization's own key (Claude, OpenAI, Gemini or compatible), encrypted on the server, with usage tracking and a monthly limit.
- **Everywhere:**
  - Every table downloads as Excel, CSV, Word or PDF, prints with your logo, and shares as an expiring link.
  - Backups, restore and duplicate.
  - Roles that see only what's theirs, an activity log, themes and dark mode, and animation that respects reduced motion.

## Known limitations

- The installers were tested on Linux (`install.sh`, end to end on a fresh copy) and in Docker (build, first start, setup, PDFs, restart). `install.sh` hasn't been run on macOS, nor `install.ps1` on Windows, yet.
- Flow hasn't been tried with a real AI model yet (no key was available while building); the provider connections were checked as far as "key refused".
- Office files were checked part by part and in LibreOffice, not yet in Microsoft Office.
- No email or SMS sending yet: invitations and reminders are links and in-app notifications.

The full list is in [CHANGELOG.md](https://github.com/mayarakwad/TamamERP/blob/v1.0.0/CHANGELOG.md) and the [README](https://github.com/mayarakwad/TamamERP/blob/v1.0.0/README.md).
